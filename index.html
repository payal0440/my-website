Introduction to Web Hosting

Every website is made of HTML, CSS, JS, images. Visitors can reach them only if stored on a computer always on and connected to internet. That computer is called server.

Your files

HTML, CSS, JS, images, database

The host

Company that keeps servers powered, cooled, secured

The domain

Readable name like example.com

How Web Hosting Works

Stage 1: Domain

You register a name with registrar. Name holds no website, only points.
